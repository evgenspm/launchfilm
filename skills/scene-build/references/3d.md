# 3D: devices in a studio with React Three Fiber

Use 3D only when the device or the object is the story (vocabulary: `device-3d`, `orbit-3d`, `extrude-type`, `physics`,
`orbit`). A 2.5D CSS device (`DeviceFrame`, tilt plane, craft/families/screen.md) covers most launch films at a fraction
of the render cost. Recipes with 3D are `render_cost: heavy`.

## Setup

- `@remotion/three` `ThreeCanvas` with explicit `width` and `height` (from `useVideoConfig()`); drive everything from
  `useCurrentFrame()` inside the canvas, never from R3F's clock or `useFrame` deltas.
- GL renderer (remotion.config / render flags): `angle` on macOS; `swangle` (CPU, slow, always works) or `egl`/`vulkan` on
  Linux with a GPU; CI uses `swangle`. Doctor reports which one works; read it before rendering.
- Render concurrency 2 for 3D shots; render 3D sections separately if the rest of the film can go faster.

## Headless capture gotchas

1. `delayRender` until the GLB, the HDRI and every texture have loaded (a `Ready` child inside `Suspense` that calls
   `continueRender`).
2. Before `continueRender`, invalidate/advance the scene and wait **two `requestAnimationFrame` ticks**: the first draw
   after a remount (shader compile, reflector FBO, post-processing composer) captures black otherwise.
   Symptom: the first N frames of a 3D sequence are black, N = render concurrency.
3. Sticker planes that sit off the focus plane: `depthWrite={false}` and bokeh ≤ 0.5, or DOF halos them.
4. Measure the model, don't guess: reset node position to 0 before reading its bounding box, then subtract the centre
   (a node cloned with its local offset ends up off-centre or mirrored). Find a device's display mesh by its UV range
   0..1, not by size.
5. Screen content is a texture rendered from React at the panel's pixel size (e.g. 2560×1664 for a 14" laptop); oversize
   UI type ~2.5× because the panel is seen small.

```tsx
const [handle] = useState(() => delayRender('glb+hdr'));
const Ready = () => {
  const {invalidate, advance} = useThree();
  useEffect(() => {
    invalidate(); advance(0);
    requestAnimationFrame(() => requestAnimationFrame(() => continueRender(handle)));
  }, []);
  return null;
};
// <Suspense fallback={null}><Model /><Environment files={hdr} /><Ready /></Suspense>
```

## Look

ACES tone mapping, exposure ~1.1; one key light, one rim light in the brand accent from behind, HDRI fill ~0.75; floor
reflection mirror ~0.4 with blur; fog to the background colour; post: shallow DOF on the subject, bloom ~0.6 above a
0.85 threshold, vignette. The camera is never static: an arc (angle, distance, height, look-at) eased with named easings,
DOF target following the subject.

## QA (black frames)

Every black frame must be intentional:
`ffmpeg -i out.mp4 -vf "signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-" -f null - 2>/dev/null | awk '/pts_time/{split($0,a,"pts_time:"); t=a[2]} /YAVG/{split($0,b,"="); if (b[2]+0 <= 20) print t, b[2]}'`
prints `time YAVG` for every frame with YAVG ≤ 20 (8-bit limited range: pure black = 16). Any 3D shot whose first frames are black fails until fixed with
gotcha 2.

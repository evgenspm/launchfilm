# 07 · Footage: where the pictures come from

A launch film lives or dies on pictures with a point of view. "Person smiling at a laptop" is tell T9 (craft/00).
This file ranks the sources, sets the rules for optional AI footage, and fixes how every clip is recorded.
Rebuilding the product UI has its own file: craft/13.

## Sources

Ranked by how much they help a launch film. Use the highest rank that can carry the shot.

| Rank | Source | Use for | Rules | Vocabulary |
|---|---|---|---|---|
| 1 | **Product UI rebuilt in React** | every product beat | real tokens and components, scripted data, crisp at tier 4 zoom (craft/13) | `ui-rebuild` |
| 2 | **The user's screen recordings** | UI too big or too live to rebuild (maps, editors, 3D, long flows) | 2× capture, 60 fps, punch-in limit from craft/13; treat as footage: camera wrapper, grade, cursor | `screen-recording` |
| 3 | **The user's device and photo footage** | warmth, scale, "real people use it" | phone on a table, hand in frame, natural light, shallow depth of field; film the real app, never a mockup over a moving phone unless the track is clean | `device-phone`, `device-laptop` |
| 4 | **Archival and public domain** | manifesto openings, history beats, metaphor | verified public domain or CC0 only (see below); downscale to 720p and add grain so it reads archival | `film-look`, `grain` |
| 5 | **Stock** | hands, streets, crowds, texture | graded (craft/06), cut at 0.5–1.5 s, one strong motion, subject centred | `film-look` |
| 6 | **AI-generated** (optional, paid key) | metaphors you cannot film, period settings, impossible shots | rules in the next section; never the product UI, never text | n/a |

Minimum per film: launch films use ≥ 3 sources (montage needs variety under one grade); product films use 1–2 (rank 1, maybe rank 2).

### Archival and public domain: verification

| Check | Pass condition |
|---|---|
| Licence on the item page | "Public Domain", "No known copyright restrictions", CC0, or a US federal work |
| Not a re-upload | the page is the holding institution or the original uploader |
| No people in a commercial context | recognisable people are not presented as endorsing the product |
| Record it | a row in `footage/SOURCES.md` with the item URL (see Provenance) |

Good starting points: national libraries and archives, space agencies' image libraries, Wikimedia Commons (filter PD/CC0),
the Internet Archive (check each item; many uploads are not PD). The harness defaults to **no** news footage, no
celebrity likeness and no other company's ads. Commentary or fair-use calls are the user's legal decision, not the agent's.

### Stock

- Free stock (no attribution) is fine inside a finished video. Never commit the files to a public repo (most licences forbid
  redistributing the raw files; craft/12 has the same rule for audio).
- Pick clips with one clear motion and a centred subject. Reject clips with logos, visible brand names or readable screens.
- Cut on the motion's peak, not before it. Use 0.5–1.5 s. Longer stock shots expose themselves.

## Generated footage (optional)

Off by default: no image or video model has a usable free tier. Enabled only with the user's key in `launch-video/.env`
and a provider in `harness.config.json` → `providers`. **Model ids churn** (several video and image ids were retired in
2026): read the id from config, never hardcode it, and record it per clip.

### Prompt grammar

`<subject and one action>, <setting and era>, <camera: lens, one move, framing>, <lighting>, <film stock or grade>, <mood>`

Example (fictional, for an invoicing app's "paper era" opening):
"an accountant's desk piled with carbon-copy invoices, 1970s office, 50 mm lens, slow push-in, framed from above at 45°,
warm tungsten light, 16 mm film grain and halation, quiet and tired".

| Rule | Number / check |
|---|---|
| One camera move per clip | push-in or lateral dolly; two moves cut badly |
| Generate long, use short | generate 6–8 s, use 1–3 s; cut before artifacts register (hands, faces, physics) |
| Lock composition | first frame from a generated still when the provider accepts an image input |
| Character consistency | pass reference images; still expect drift; keep faces small or out of frame |
| Negative prompt defaults | "text, letters, watermark, subtitles, logo, extra fingers, morphing hands, jitter" |
| Specific stock in the prompt | gives grain and halation you can match in post (craft/06 grade) |
| Audio from video models | strip it (`-an`); rebuild sound from the library (craft/12). Generated audio often carries stray voices |
| Generated stills | 1–2 s on screen with a push-in read as footage (`push-in`, craft/03) |

### Never

- Text baked into generated images or video. All type is rendered in Remotion (craft/05). Generated text misspells and
  cannot be edited, translated or re-timed.
- The product UI generated by a model. It lies about the product. Rebuild it (craft/13).
- Real people's likeness (public figures, staff, customers) without written consent. No news footage look-alikes.
- Other companies' logos or products in frame.

### Disclosure

Record provider and model id per clip in `footage/SOURCES.md`. Some providers watermark output invisibly; some platforms
ask uploaders to label AI-generated realistic footage. Tell the user which clips are generated before they post.

## Consistency

Mixed sources look like a moodboard unless one treatment unifies them (craft/06#grade-discipline).

| Rule | Check |
|---|---|
| One treatment per section | every clip in a section passes through the same grade stack (tint, grain amount, vignette) |
| Match sharpness | downscale sharp sources to the softest source's level; the eye catches a sharpness jump before a colour jump. Check: two neighbouring stills at 100 % look equally soft |
| Match by geometry | subject centred, or the same shape at the same position across the cut (`match-cut`, craft/09) |
| Match motion | each clip carries one motion; add drift (craft/03#drift-and-push-in) to any clip without one |
| Frame rate | conform everything to the composition fps; no 24 → 30 judder on pans (use `OffthreadVideo` / `@remotion/media` `Video`, never a pre-converted GIF) |
| Loudness of clip audio | clip audio off by default; if used, it goes through the mix (craft/02#mix) |

## Provenance

Every film keeps `films/<slug>/footage/SOURCES.md` (with the film source). The files themselves live in
`public/films/<slug>/footage/` so `staticFile` can reach them. One row per file. No row, no clip in the render (film-qa blocks on it).

```
| file | kind | source URL | licence | author | AI prompt + model id | modified |
|---|---|---|---|---|---|---|
| public/films/<slug>/footage/desk-1970.mp4 | ai-video | provider console | provider terms (paid plan) | generated | "an accountant's desk ..." · <model id from config> | trimmed 1.2 s, graded |
| public/films/<slug>/footage/press.mp4 | archival | https://<archive item page> | Public Domain | <institution> | n/a | 720p, grain 0.12 |
| public/films/<slug>/footage/app-tour.mov | screen-recording | user | user-owned | user | n/a | punch-ins, cursor kept |
```

- `licence` names the exact licence (CC0 1.0, Public Domain Mark, provider terms + plan). "Free" is not a licence.
- `modified` lists what changed (trim, crop, grade, speed). CC BY sources also go into `out/<slug>/credits.txt` (craft/12#credits-and-content-id).
- Generated clips keep the prompt verbatim so the user can regenerate or disclose.
- Raw footage stays in the user's project. The harness repo ships no third-party footage.

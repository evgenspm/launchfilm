# Changelog

## 0.1.0 (2026-10-17)

- First version: studio (presets, film engine, components, 5 demo brands), 9 skills, craft docs, CLI with free providers (Kokoro, whisper.cpp, procedural SFX, library music), installer, recipe schema and reference prep.

- Release documentation links the Sharpy film and its breakdown, lists the bundled fonts and downloaded music, and distinguishes supported providers from future adapters.
- Reinstall preserves custom sound catalog entries and aborts before changing files when the existing catalog is malformed.
- Interrupted installs can be retried, and first-use local transcription creates its model cache before downloading.

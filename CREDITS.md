## Prior art and ideas

We read these, learned from them, and wrote our own text and code. Nothing below is vendored.

| Source | What we took (as an idea) |
|---|---|
| [HyperFrames](https://github.com/heygen-com/hyperframes) (Apache-2.0) | One `skills/` folder wrapped in thin per-agent manifests; a gated launch pipeline with a hard stop when brand capture fails; snapshot QA |
| [launchvideo.dev](https://launchvideo.dev) | Story before scenes, rebuilding the product UI from real components, four zoom tiers, checking frames against framing rules before rendering |
| [remotion-dev/skills](https://github.com/remotion-dev/skills) | Router skill with embedded references. Not vendored (no license file); install it separately if you want Remotion's own skills |
| [Screen Studio](https://screen.studio) open-source effect algorithms | Spring values for cursor follow and auto-zoom (stiffness 170 / damping 20, 700 / 30, 136 / 26) |
| [Emil Kowalski](https://emilkowal.ski)'s animation writing | Ease-out to enter, ease-in to leave, animate transform and opacity, springs for physical motion |
| [brag](https://github.com/latent-spaces/brag) (MIT) | A designed poster frame at frame 0; share copy written with each render |
| [Agent Skills](https://agentskills.io) specification | Skill format and progressive disclosure |
| [llms.txt](https://llmstxt.org) | Docs index format |

Measured numbers in `craft/` (frame counts, scales, blur radii, shot lengths, loudness) come from studying published
launch films and templates frame by frame. We publish the measurements and our own rebuilds, never the source media or
its copy. Recipes link to their source by URL.
